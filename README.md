# Blinkit Discovery Engine

An AI-powered research engine that analyses public user feedback about Blinkit at scale (Play Store, App Store, Reddit, YouTube, forums). It explains why quick-commerce shoppers keep buying from the same categories, and what would get them to try new ones.

**Status:** early build, Part 1 (discovery engine) in progress.

- Architecture: [docs/part1-architecture.md](docs/part1-architecture.md)
- Walkthrough: [docs/WALKTHROUGH.md](docs/WALKTHROUGH.md)

Stack: Python · GitHub Actions · Groq · Supabase (Postgres + pgvector) · Next.js on Vercel. Free tiers only.
